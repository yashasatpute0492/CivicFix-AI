# CivicFix AI

**An AI-assisted civic issue reporting and prioritization platform.**

CivicFix AI is a web application designed to help citizens report local civic problems, identify potential duplicate complaints, and understand which issues may need urgent attention.

## Problem Statement

Problems such as potholes, broken streetlights, overflowing garbage, and water leakage can affect public safety and community well-being. CivicFix AI provides a simple interface to record and organize these issues.

## Features

- Submit civic complaints with relevant details.
- Categorize issues such as roads, sanitation, streetlights, and water supply.
- Assign priority scores using a rule-based scoring system.
- Detect potentially duplicate complaints.
- Search and filter reported issues.
- Track complaint statuses within the application.
- Store demo data locally in the browser.
- Export complaint data as JSON.
- Responsive interface for different screen sizes.

## Technology Stack

- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Submit a test complaint and explore the dashboard.

## Important Limitations

This is a prototype. Complaint information is stored locally in the user's browser and is not automatically sent to government authorities. The current priority scoring and duplicate detection use rule-based logic; they do not require a trained AI model or external AI API.

## Future Improvements
